# 직원현황 · 조직연락망

브라우저에서 직원현황과 조직연락망을 관리하는 로컬 HTML 도구입니다. 조직별 인력 기준, 조직 구성, 직원 사진·내선, Excel 등록, JSON 백업, 보고서 인쇄를 지원합니다.

## 시작

- `직원현황_범용양식.html`: 조직·부서와 고용형태·정원 기준을 설정하고 직원을 관리합니다.
- `조직연락망_범용양식.html`: 조직도를 설정하고 재직 직원의 사진·역할·내선번호를 관리합니다.
- `인구전략위원회_직원현황.html`, `인구전략위원회_조직연락망.html`: 인구전략위원회용 설정을 포함한 도구입니다.
- `인구전략위원회_조직구성.json`: 범용 양식에 불러올 수 있는 조직 구성 예제입니다.

자세한 순서는 [범용양식 사용안내](범용양식_사용안내.md)를 참고하세요.

## 인력·조직 집계

인력 기준표에 인력 구분, 고용형태, 정원 내외, 정원·기준인원을 연결합니다. ‘기타’도 정원 내·외로 나눠 설정할 수 있습니다. 조직 구성은 직원이 있는 부서 수가 아니라 등록된 조직 단위를 처·본부·국·과·팀 등으로 집계하며 공석도 포함합니다. 부위원장 같은 직위는 제외하고, ‘사무처장’처럼 부서를 대표하는 직위는 ‘사무처’로 집계합니다. 부서와 부서장 노드를 함께 등록해도 같은 조직은 한 번만 셉니다.

## Kordoc 연결

Node.js 20 이상 설치 후 Windows에서 `Kordoc_연결실행.cmd`를 실행합니다. 최초 패키지 설치와 OCR 모델 다운로드에는 인터넷이 필요합니다.

- 연결 화면: http://127.0.0.1:8765
- 문서·이미지에서 조직명 후보 추출 후 상위 조직 확인·적용
- 직원현황의 요약 보고서·명부를 편집 가능한 HWPX로 저장

[Kordoc 연결 사용안내](kordoc-bridge/사용안내.md)

HTML을 파일로 열었을 때와 로컬 서버 주소에서 열었을 때는 저장 공간이 다릅니다. 기존 자료는 JSON 백업으로 옮길 수 있습니다. 다른 사람에게는 연락망의 ‘배포용 HTML 저장’ 파일을 전달하세요.

## 데이터 보관

직원 데이터는 브라우저 저장소에 보관되며 자동으로 서버나 GitHub에 동기화되지 않습니다. 저장소에는 프로그램 소스와 조직 구성 예제만 포함합니다. 직원 백업, 작성된 Excel, 사진이 포함된 배포본, 설치된 의존성, 검증 산출물은 `.gitignore`에서 제외합니다.

## 검증

```powershell
node tests/organization-summary.cjs
```

Kordoc 서버를 실행한 뒤 아래 통합 검증도 사용할 수 있습니다.

```powershell
node kordoc-bridge/verify.mjs
node kordoc-bridge/verify-hwpx.mjs
```

Kordoc은 별도 오픈소스 의존성입니다. 저작권·라이선스는 해당 패키지를 참고하세요. HTML에 포함된 SheetJS CE는 Apache-2.0 라이선스입니다.
