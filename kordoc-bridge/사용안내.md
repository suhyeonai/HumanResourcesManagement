# Kordoc 로컬 연결

1. 상위 폴더의 `Kordoc_연결실행.cmd`를 실행합니다. Node.js 20 이상이 필요합니다.
2. 브라우저에서 http://127.0.0.1:8765 를 엽니다. 범용 양식은 이 화면의 Kordoc 연결 버튼으로 열거나 주소 뒤에 범용 HTML 파일명을 붙입니다.
3. `조직 설정` → `Kordoc 문서 불러오기`에서 이미지, PDF, HWP, HWPX, DOCX, PPTX를 선택합니다(20MB 이하).
4. 추출 텍스트와 조직명 후보를 확인하고, 불필요한 후보를 삭제한 뒤 상위 조직을 지정합니다.
5. `조직 적용`을 눌러 반영합니다. 직원 연락망 배포는 기존 `배포용 HTML 저장`을 사용합니다.

Kordoc은 문서·한국어 OCR 도구이며 조직도 연결선의 상하 관계를 확정하는 AI 서비스가 아닙니다. 후보는 확인 전 현재 연락망을 덮어쓰지 않습니다. 외부 AI API 키는 필요하지 않습니다.

파일을 직접 열었을 때와 로컬 주소에서 열었을 때는 브라우저 저장 공간이 다릅니다. 기존 데이터는 먼저 연락망 편집본 JSON으로 백업한 뒤 로컬 화면에서 불러오세요.

최초 패키지 설치와 한국어 OCR 모델 다운로드에는 인터넷이 필요합니다. 이 PC에는 Kordoc 4.24.14와 OCR 모델을 설치·검증했습니다. 다른 PC에서는 같은 폴더 구조로 배포하고 실행 파일로 설치합니다. 실행 창을 닫으면 연결도 종료됩니다. 서버는 이 PC의 127.0.0.1에서만 대기합니다.

업로드 파일은 운영체제 임시 폴더에서 분석한 뒤 삭제합니다. 원문이나 추출 결과를 외부 AI에 보내지 않습니다.

공식 사용 문서: https://github.com/chrisryugj/kordoc/blob/main/docs/usage.md

검증: `node kordoc-bridge/verify.mjs` (서버 실행 후). 실제 DOCX와 한국어 이미지 OCR을 테스트합니다.

## 직원현황 한글문서 저장

로컬 연결 화면에서 `직원현황_범용양식.html` 또는 `인구전략위원회_직원현황.html`을 엽니다. 기능 추가 전부터 연결 프로그램을 실행하고 있었다면 종료 후 다시 실행하세요.

- **요약 보고서 HWPX 저장**: 검색 조건과 관계없이 전체 인력 운영 현황, 인력 구분별 정원·현원·미충원·초과 및 재직·휴직·병가를 표로 저장합니다. 개인 명부와 연락처는 포함하지 않습니다.
- **직원 명부 HWPX 저장**: 현재 검색·부서·상태·정렬 결과를 저장합니다. 기본 명부와 원소속·담당자 연락처를 별도 표로 구분합니다.

생성 파일은 A4 가로 방향의 편집 가능한 한글 표와 글자로 구성됩니다. HWPX 형식이며 기존 HWP 바이너리 형식은 아닙니다. 한글 프로그램에서 열어 수정·인쇄할 수 있습니다. 명부가 많으면 여러 쪽으로 나뉩니다.

파일을 직접 연 화면에서는 생성 버튼 옆의 **Kordoc 직원현황 열기** 링크를 이용하세요. 저장 공간이 다르므로 기존 데이터는 JSON 백업으로 가져오면 됩니다. 파일은 이 PC에서 생성해 다운로드하며 별도 서버에 보관하지 않습니다.

생성 기능 검증: `node kordoc-bridge/verify-hwpx.mjs` (서버 실행 후). 생성·구조 검사·재읽기 및 보고서 미리보기를 검증합니다.
